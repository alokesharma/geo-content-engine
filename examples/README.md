# Example output

`sample-final-doc.md` is a shortened example of what the engine writes to `runs/<date>-<slug>/final-doc.md`.

It shows the shape of a finished run: a QA block at the top (which you delete before publishing), then the article, then the FAQ and Key Takeaways. The prose passes the same anti-AI-writing gate the engine enforces, so you will not find an em dash, a curly quote, or a "not X but Y" in it.

This sample was trimmed for length. A real run targets the length and heading count of the top-ranking pages for the topic, which is usually longer.
